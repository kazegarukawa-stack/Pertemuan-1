# Laporan Keuangan Mahasiswa

Project ini merupakan halaman web sederhana untuk menampilkan laporan
pengeluaran mahasiswa selama bulan September 2026. Halaman dibuat
menggunakan HTML dan CSS tanpa framework tambahan.

## Fitur

-   Menampilkan judul dan keterangan laporan keuangan.
-   Menampilkan daftar 10 kebutuhan/pengeluaran mahasiswa.
-   Menampilkan tanggal, jenis kebutuhan, dan jumlah pengeluaran.
-   Menampilkan total pengeluaran pada bagian bawah tabel.
-   Menggunakan warna dan tata letak sederhana agar tabel mudah dibaca.

## Teknologi yang Digunakan

-   HTML5
-   CSS3
-   Visual Studio Code
-   Live Server (untuk menjalankan halaman secara lokal)

## Struktur File

``` text
project/
└── index.html
```

## Cara Menjalankan

1.  Buka folder project di Visual Studio Code.
2.  Buka file `index.html`.
3.  Pastikan ekstensi **Live Server** sudah terpasang.
4.  Klik kanan pada file `index.html`.
5.  Pilih **Open with Live Server**.
6.  Halaman laporan keuangan akan terbuka di browser.

## Data Laporan

Laporan berisi 10 jenis pengeluaran pada bulan September 2026, yaitu
uang bensin, buku dan alat tulis, belanja bahan makanan, transportasi,
paket internet, fotokopi dan cetak tugas, perlengkapan mandi dan
kebersihan, uang main/bulanan, obat dan kebutuhan kesehatan, serta iuran
kegiatan kampus.

**Total pengeluaran: Rp1.020.000**

## Catatan

File utama project adalah `index.html`. Untuk mengubah judul, tanggal,
nama kebutuhan, atau nominal pengeluaran, edit bagian HTML yang sesuai.
Untuk mengubah tampilan halaman, edit aturan CSS di dalam tag `<style>`.
